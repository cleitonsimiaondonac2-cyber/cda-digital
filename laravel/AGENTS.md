# Laravel — notas para agentes

Esta pasta é a fundação Laravel 13 do projecto CDA Digital 3.0.

- Segue as regras do repositório em `../README.md` e em `../docs/`.
- Não instales `laravel/boost` nem alteres o site actual em `../site/`.
- Configuração local em `.env` (fora do Git); base PostgreSQL em `127.0.0.1:5433`.
- Comandos: `php artisan serve`, `php artisan migrate`, `php artisan test`,
  `npm run build`. Ver `README.md`.
